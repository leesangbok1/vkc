# UI Wireframe Tracker

본 문서는 화면/배너 와이어프레임 업데이트 현황을 기록하는 전용 로그입니다.
패턴화 · 게시글 우선 · 직관적 UX 원칙에 따라 변경한 사항을 아래 섹션에 순차적으로 갱신합니다.

## 원칙
- 모든 화면은 `PageFrame`/`Section`/`SidebarRail` 패턴을 기반으로 설계한다.
- 상단 필터 바는 48px 이하 컴팩트 형태로 헤더 바로 아래 배치하고, 스크롤 시 고정한다.
- 메인/전체 게시글/답변 작성/마이페이지/관리자/배너 UI는 동일 `PostCard` 메타 구조를 사용한다.
- 모바일 퍼스트(min-width) 브레이크포인트를 기준으로 레이아웃을 정의하고, 데스크톱 확장은 960px 콘텐츠 폭을 기준으로 한다.

## 메모
- 목업 파일은 `claudedocs/mockups/` 폴더에 저장하고, 파일명 규칙은 `YYYYMMDD_<화면명>_v1.fig` 형태를 따른다.
- 와이어프레임 변경 시 `claudedocs/WORKLOG.md`에도 간단히 링크와 함께 기록한다.
- User Rank · 미션 화면은 `20251027_user-rank-wireframe_v1.fig` 기준으로 문서화되며, 향후 실데이터 연동 시 DTO 정의 필요.
