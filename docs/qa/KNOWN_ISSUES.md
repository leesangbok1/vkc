## Known Issues & Mitigation Plan (2025-10-27)

### 1. API 응답 에러 처리 미흡
- **영향 범위:** `ProfileModal`, `NotificationSetupModal`, `LoginPromptModal` 등 `/api/**`를 직접 호출하는 모달/섹션.
- **증상:** 비정상 응답(401/500)이 발생하면 UI가 멈추거나 콘솔 예외가 발생.
- **조치:** 공통 fetch 헬퍼를 도입해 401/500 대응(상태 초기화 + 안내 메시지) 후 재시도 가능하도록 한다.

### 2. 팔로우/북마크 자기 자신 액션
- **영향 범위:** 홈 피드, 추천 모달, 사용자 상세 등 팔로우/언팔로우 버튼이 있는 모든 곳.
- **증상:** “You cannot follow yourself.” 서버 에러가 콘솔에 노출됨.
- **조치:** 공통 유틸(`follow-manager`) 및 각 UI 버튼에서 현재 사용자 ID와 대상 ID 비교 후 요청 자체를 막는다.

### 3. 비로그인 조회 시 불필요한 API 호출
- **영향 범위:** 토픽 구독, 팔로우 상태 조회 등 로그인 전에도 호출되는 fetch.
- **증상:** 콘솔에 401/경고가 반복되고 응답 지연 초래.
- **조치:** `!isLoggedIn`인 경우 해당 API 호출을 생략하거나 커스텀 안내를 띄워 서버 부하와 경고를 줄인다.

### 4. 서비스 클라이언트 미사용 API
- **영향 범위:** `/api/users/[id]`, `/api/users/recommended` 등 타 사용자 데이터를 읽는 API.
- **증상:** RLS 정책 때문에 42501 (insufficient privileges) 발생 가능.
- **조치:** 서비스 롤 클라이언트 우선 사용 및 폴백 로직 추가. RLS 정책이 필요한 경우 별도 마이그레이션 작성.

### 5. 세션 만료 시 피드가 빈 상태로 머무는 문제
- **영향 범위:** `FeedBoard`, 홈/토픽/팔로잉 탭 등.
- **증상:** 세션 만료 후 API가 401, UI는 빈 리스트로 남아 사용자 혼란.
- **조치:** 401 감지 시 로그인 유도 배너를 띄우고 기존 아이템을 유지하거나 명확한 메시지를 보여준다.

### 6. 헤더/사이드바 프로필 호출 실패 시 예외
- **영향 범위:** `Header`, `Sidebar`.
- **증상:** `/api/auth/profile`가 500이면 드롭다운/메뉴가 깨질 수 있음.
- **조치:** 기본값 가드 + 오류 안내 토스트 추가.

### 7. 팔로워 모달 추천 탭 중복 클릭
- **영향 범위:** 추천 탭 팔로우 버튼.
- **증상:** 빠른 연속 클릭 시 API 중복 호출, 상태 경합.
- **조치:** 버튼 비활성화(pending 상태)와 optimistic update 롤백 로직을 강화한다.

---

### 2025-10-27 변경사항
- 공통 fetch 헬퍼(`safeJsonFetch`) 적용으로 홈/토픽/팔로워 모달/인기 사용자 페이지의 오류 처리를 통일.
- 팔로잉/팔로우 토글을 공통 유틸(`toggleFollowUser`) 기반으로 통합하고 self-follow 방지 로직을 도입.
- `/api/users/popular`, `/api/users/recommended` 등 타 사용자 조회 API에 서비스 클라이언트 사용을 우선 적용.
